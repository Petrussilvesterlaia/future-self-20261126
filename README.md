("Texts From Your Future Self").

## What it does

`main.py` (Python standard library only) writes exactly one text message
— a funny message from the writer's future self back to their present
self — to `/output/entry.txt`. The message is under 200 characters,
exactly one line, and the program validates that before writing.

## Run it

```sh
python3 main.py
```

Then check the entry:

```sh
cat /output/entry.txt
```
